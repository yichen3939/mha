雲端連線設定(Firebase)

這個網頁已經內建你的 Firebase 連線設定，打開網頁就會自動連線，不需要再手動貼設定。 這個分頁只有在你想「換一個 Firebase 專案」時才需要用到：貼上新的設定並按下方按鈕即可覆蓋內建設定。

申請步驟：
1. 前往 console.firebase.google.com，登入 Google 帳號，建立新專案。
2. 專案建立後，左側選「建構 → Firestore Database」，選「以測試模式建立」。
3. 進入 Firestore 的「規則」分頁，暫時設定為 allow read, write: if true;（僅供個人小工具使用，注意這代表任何人拿到專案設定都能讀寫資料）。
4. 回到「專案總覽」，點選網頁圖示 </> 新增網頁應用程式，取名後會出現一段 firebaseConfig 物件，把整段大括號內容複製貼到上面的欄位。
